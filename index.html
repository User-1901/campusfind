🔬 Critical System Insights

  • Hardware Invariance of Comparisons: While wall-clock execution time fluctuates with CPU clock and memory caching, the number of comparisons is a pure mathematical invariant.
  • Asymptotic Milestone: For $N = 10,000$, Linear Search requires up to 10,000 comparisons in the worst case, whereas Binary Search resolves in at most 14 comparisons ($2^{14} = 16,384 > 10,000$).
  • Separation of Overhead: Sorting an unsorted array takes $\mathcal{O}(n \log n)$ time. In search engines, this cost is paid once during offline indexing, enabling subsequent searches in microsecond $\mathcal{O}(\log n)$ time.

🧠 Inverted Index vs. Sorted Vocabulary

Inverted Index: A dictionary mapping words to their locations in documents:

{
  "examination": {
    "doc_01_exam.txt": [12, 45],
    "doc_02_admit.txt": [8]
  }
}

Sorted Vocabulary: Lexicographically ordered unique word keys enabling Binary Search $\mathcal{O}(\log n)$:

["academic", "calendar", "circular", "examination", ...]
